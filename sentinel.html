CORE MATHEMATICAL LOGIC
WHALE CONCENTRATION INDEX (WCI)
WCI = Position_Size / Pool_24h_Depth

Flag if WCI > 0.15 (15% of pool depth)
Measures if a single entity can "choke" DEX liquidity upon forced liquidation. WCI > 0.15 triggers Whale Alert. WCI > 0.30 initiates War Room Protocol.
DEADLOCK PROBABILITY (DP)
DP = (HF x LT ) / Debt_Value

Deadlock if HF < 1.0 AND WCI > 0.10
Measures probability that a liquidation will fail and create bad debt. Combines Health Factor with Liquidation Threshold to detect "trapped" protocol positions.
ORACLE DEVIATION GAP (ODG)
ODG = |Oracle_Price - CEX_Mid_Price |

Alert if ODG > 2% of CEX price
Detects manipulation between on-chain and off-chain prices. ODG > 2% indicates potential Oracle Extractable Value (OEV) attack or price feed compromise.
BAD DEBT PREDICTOR (BDP)
BDP = Borrow_Value - (Collateral_Value x 0.90)

Stress test at -10% and -30% price drop
Estimates bad debt created if price drops 10% or 30%. Used in Live-Fire drill simulations to validate playbook effectiveness before deployment on mainnet.
